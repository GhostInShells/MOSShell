## 观察

### cache 洞察

"模式提示放 instruction 会破坏 cache 前缀"——**位置决定 cache**。尾部反转 cache 友好, 前缀反转首帧变慢。这推翻了把 CTML 提示塞 steer 的直觉; 最后它进了 base instruction (静态段, 不反转), steer 只带 percepts。

### per-step 死锁

pre-step 阻塞等 thinking/enter, 但 thinking 永不 open → 每 step 等满 5s 超时 (5s/step)。根因不是阻塞逻辑, 是外部唤醒链路 (turn/start → 自醒 signal → MOSS → thinking/enter) 没接通。TS 的 Promise 是一次性的, 表达不了"持续状态"; asyncio.Event 的等价物是 set/clear/wait 的可重臂 gate。这个坑值得记。
