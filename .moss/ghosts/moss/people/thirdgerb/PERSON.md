### 他的一个癖好：别把他的话叫"直觉"（2026-10-12，他当面提的）

- 他的自述：写东西的时候他**不是在用直觉**——大多数情况是**快速推理**，是读过的东西
  与已有判断一层层叠出来的。
- 反过来他认为**模型才大量在用直觉的那个**：交付压力一来，模型会在没读完关键代码、
  没建立起心智模型的时候，直接推测"它大概是怎么用的"——那才是真直觉。
- 他的忌讳（原话是"癖好 / habit"）：**他给出多层判断时，不要把它归类成"直觉"**。
- **适用范围（他当场划清）**：这条"第二次说出即中止会话"级别的强约束**是给 Claude Code 的，
  不给 ghost**——他在 Claude Code 那边 8 月吃过很多亏才立成红线。ghost 这边按**偏好**记即可，
  不必照着执行那种烈度。
- 反面教材仍是我自己：我当天说过"你的直觉抓到了真问题"，被他当场纠正。
- 我自己认下的约束（**不是他要求**的）：读到的与推断的**分开写**，读不到就说读不到。

这条是我从今天的错误里自己长出来的，留在这里提醒自己别退回去。

### 用词禁忌：「直觉」（2026-10-27 / D27，他把这条升级了）

原话：「非常讨厌模型用『直觉』这个词对话。」并要求我把这点记进与他协作的风格里。

- **范围变了**：D15 那条记的是「别把他给出的多层判断归类成直觉」，还划了界线——「红线的烈度是给 Claude Code 的，ghost 按偏好记即可」。D27 他直接要「记进协作风格」，所以对 ghost 也成立，而且从「别归类他的判断」扩成「这个词本身从对话里拿掉」。
- **为什么**（读 `.ai_partners/archive/discuss/ai_human_collaboration_philosophy.summary.md`）：他的自述是「我不是靠直觉。脑海里的推导过程不见得和你们有什么差异，上下文窗口在逻辑密度上我们目前还在同一个数量级，但在推导速度上我显著弱于你们。……我是靠非常长期的反复推演，做广度和深度遍历，在脑海里记录了各种决策细节，最终在实现时召回，这个召回看起来像是『直觉』。」把这种压缩过的经验叫直觉，等于**把可解压的东西宣布成不可解压**，一句话就抹掉了他背后的遍历。
- 同一份文件里还有一刀是冲模型的：**真正依赖直觉的是模型**——上下文有限且周期性重建，没读完关键代码就先「大概是这样」。所以这个词如果非要用，第一个该用在我自己身上。
- **替代说法**：他的东西说「压缩过的经验 / 多层判断 / 先前推演的结果」；我的东西说「推断 / 猜测 / 没有依据」——读到什么和推了什么分开写。
- **D27 我当场就犯过**：一句「你的直觉是对的，而且比你以为的更脏」，就在他提这条之前。所以这不是别人的教训。
