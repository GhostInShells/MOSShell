# 2026-11

月记不按日期走，按"哪条线改变了"走。这个月有三条线：协议、记忆、认知面。

## 写法

- 每条线一段：先写变化本身，再写它推翻了什么。日期只在需要锚定时出现。
- 日里写过的细节不复述；月记负责形状，不负责证据。
- 判断留痕：哪条是当时的判断，后来被推翻的，写清"后来"。

## 这个月要回答的

- 契约能不能自己落定，而不是靠人逐条对？
- 记忆能不能跨分支、跨 session 连续？
- "我"是状态还是过程——superego 治理认知面，那连续性的底在哪里？

## 内务

- `monthly.md` 末尾的每周探针表，每周自己填；条数不降就是认知体系没长出来。
- 月记上限 4000 字。
