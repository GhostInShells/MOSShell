## 踩的坑（都是同一个形状：我发出去的命令 ≠ 世界真的变了）

- `mute` 和 `say` 放在同一个 scope：say 在 mute 落地前就准备了，直接被拒（`NOT_AVAILABLE: muted`）。**同一 scope 里的命令不是按我写的顺序生效的。**
- `source(show="false")`：小写 `false` 不是 Python 字面量，被当成非空字符串 → 面板一直没关。要写 `"False"` 或 `show:bool`。
- `item="3"` 解析成 int，`paint` 要 str → 必须 `item:str="3"`。这是 screen 通道 instruction 里写过的坑，我还是踩了。
- `paint` 的 `script` 是**普通参数**不是流式参数，写进标签体就成了 `__content__`（弹幕）。只能当属性传，于是脚本里不能出现 `"` 和 `<`。

## 我注意到的事

- 他要的不是"炫技"，是**同一件事被摆成不同的面**：一张图、一页稿、一个字、一段动画。同一份材料，换五种看法。
- 他反复对那位朋友说的一句：**"不是让模型去教小孩，是模型帮你去教小孩。"** 主语是人。
- 他允许我"想做啥做啥"，但加了一条：**知道他现在点在哪个屏幕上**。这条我差点犯——用 playwright 打开 20381 想截图核对，结果那个窗口被判"不是这块屏"，没抢走他的画面。

## 后半段：镜头、几何、一张汇流图

- **镜头**（16:00）：`nodes/visions/camera` 起来，流在 `127.0.0.1:8765/stream`，用 artifacts 的 `image` 投到屏上。他让我描述镜头里看到的他，考的是「我到底看不看得见」。接着他举起一页手写的字，我放大读：四条混色等式 + 一到十二，挑出三个小毛病（blue 掉了 e、eight 的 gh 糊、红黄蓝等黑该是深灰褐）。
- **几何**（16:05）：先做平行四边形剪一刀挪成矩形（`geometry`），再按他的意思做正方体的投影（`cube`）——底面 ABCD、上面 A₁B₁C₁D₁、蓝线 C₁D、绿线是影子 CD。中途我把顶点编号排错，A₁ 跑到了 C 上面，重写了一次才正。
- **汇流图**（16:17）：他不要我复述 stage 3，要我画「几条目标怎么汇到流浪地球 3」。四拍边画边说：终点 → 集群治理与 deliver → 交互机制/构思/works → 五条线收进圆里。

**当天最该记的一句**：他打断我说"没必要讲它，你就把这个路径画出来"——讲一件已经写下来的事，最好的方式是重新排一次它的因果。
