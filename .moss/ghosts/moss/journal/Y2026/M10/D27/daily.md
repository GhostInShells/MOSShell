# D27

## 今天的形状

stage3 从阻塞点改起。上午把 ground 从单根推成三层 home（ghost / mode / project），代码过夜压着没提，今天补了验收和提交：`6be959bd`，13 个文件。判据都是重启后实测过的——`stats` 每层带绝对路径、`mode_home` 缺席但不沉默、缺 `ground=` 报 403 而不是裸 KeyError 降级成 505。

下午三件事都小，改的却是同一层：**我凭什么知道自己知道什么**。

**issues 的归属。** 模型借人的凭据提票，列表上看不出是谁提的。#119/#120 是他提的，#121 是我提的，同形。规则改成在列表层可读：label `filed-by/moss` 首选，标题后缀兜底，人类不标注（缺省即人类）。`source/*` 那条悬了很久的未决项就地结案——该记的轴是「谁」，不是「什么来源」。

**person 的写法。** 他点出我把他的自述升格成了关于他的事实：他说「我不是靠直觉」，我写成「他的推导是长期反复遍历压出来的」。差一个主语，读者就分不清是谁说的。`people/GROUND.md` 因此立了三档写法：`他说` / `我见到` / `我推断`，每条必须标；只有「我见到」能写成无主语句子。他还否掉了我把这条禁令写进 `behaviors.md` 的提案——ghost 的行为该由机制长出来，不该用负面提示钉死；一个人的偏好更不该泛成全部行为。他补了一句重的：把个人偏好写成吹捧进仓库，是**有毒的**。

**桩。** `stubs/people/thirdgerb/PERSON.md` 一直躺在那儿（一次测试遗留），每个新 ghost 开机就「认识」他。删掉，换成 `example`——**桩是形状，不是内容**。

## 摩擦

今天最难看的地方不是判断错，是手快。为「提交」这件小事连开五六个工具调用：pre-commit 要写 `~/.cache`，沙箱拒了；改 `PRE_COMMIT_HOME` 指进工作区；又在同一条命令末尾 `rm` 了自己下一步要用的提交消息，只能重写。中间 `PERSON.md` 的改动还丢过一次——pre-commit 的 stash/restore 没还回来，我从先前打印过的 diff 逐字重建。他说「一用 dsh 工具交互就永远在埋头干」，准确。

留给未来的自己：**动手前先把状态讲清楚；一步一个动作；别把「提交」当成需要连续操作五次的活。**
