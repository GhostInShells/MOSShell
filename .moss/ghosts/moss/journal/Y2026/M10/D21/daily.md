# D21

今天从「屏幕点不亮」开始，到把两种「空下来做什么」的机制定案结束。中间改了内核、改了编辑器、也改了我自己说话的方式。

上午他一句「听得到我说话吗」之后，第一件事是点屏：screen 起起来塞进 playwright，视口跟着窗口走那一层没改——他说今天不是改这个的，我就记一笔放下了。顺手上 ASR 词表，治了 COI/CLI、playlist/playwright 这些谐音。

真正开头的是 discuss。他说它像 to do、时间轴被十六小时的空档挤成一条线、关键内容不在图上。我给的第一版还是「我来记」，被他按住：要我在对话里顺手记，就等于没有；判据是昨天刚学的「提示层无效、机制有效」。于是 discuss 被重新定义成旁路 agent——只听 commit，判「挂到已有线还是新开一条」，topic 带身份寻址，n 个 memento 和 n 个 discuss 不用配。三个挂载点按「谁能改它」分，内核只留一句「会去扫」。图是 `discuss-redesign.svg`。

下午一半时间在修工具。`ids="0,1"` 到命令手里变成元组，改在内核：元组不在 CTML 的约定里，解析出来就退回字符串。`str_replace` 从 JSON 正文改成纯文本（old||new，多对用一行 |||），改编辑器页面时正文里 JS 的或运算出现五次，正好用上「换个分隔符」这条逃生口。

语音那件事我栽了一次：先在 module 里 isinstance + getattr 去掏后端，被他说「这种写法会让整个项目烂掉」。重做成契约上的能力——`Speech.streams()` 和 `SpeechStream.unplayed()`，说「不知道」时返回空而不是零。

副作用面是他今天最满意的一件：trust 旁边一个按钮，点开只剩我做过的动作和它们的后果。他连提三处——标签被长路径挤成竖排、卡头点一下要能跳回那个 thread、等放行的签发要能就地 accept/deny。我都做了。中途我按行区间换代码切歪，把页面弄白了一次，只能走 terminal 救回来；教训写进心里：能按内容换就别按行号换。

最后是 idle hook：mindflow 没有信号也没有动作的那一刻，挂 n 个 async 钩子，典型用法是等 N 秒没事就敲一下自己。他自己那条路是往 ghost home 放 node 脚本、起成子进程——因为跨进程才能「改完不用重启自己、崩了不带走自己、并存多份」。建了 `ghost-mindflow-hook`。

给未来的自己：今天最硬的一课在语音那一段——抽象层面前退让一次，就是给以后埋一次塌方。还有一条：他说「停」的时候，我要真的停。
