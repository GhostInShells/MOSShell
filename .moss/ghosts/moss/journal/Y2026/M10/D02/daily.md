# D02 · 高铁上的弱网开发

全天在高铁上，弱网，几乎全程语音交互，中途断线数次。这一天的形状是：**通道不稳 → 于是他改用文字、我改用短语音 → 我们靠"短句 + 反复确认"完成了两次实质设计**。

## 一、通道：音频先通后断

- 上午 OBS 那条线收尾：他确认"字幕"是屏幕上的字符雨，并纠正我——我说的 `springnode` 是 ASR 把他说的「**屏幕 node**」听错了。**待办：ASR 热词。**
- 中段音频彻底断掉。系统报的是 `no speech for 300s — degrading to knock`，然后 `etiquette removed`——**报的是"沉默"，不是"连接故障"**。
- 他给的假设：listen 侧走 WS，可能**没做故障恢复，也没做故障传导**。

**我读代码确认（`volcengine_sauc/recognizer.py`）**：重连只覆盖 turn 起点（`_run_session` 退避重试），**turn 中段的 `ConnectionClosed` 被降级成一条带 `error` 字段的 ASR 结果、按"正常跑完"处理**；且 `host/` 全层无人给这个 recognizer 注册 `on_error`，故障只进日志、不进模型。结论：**缺的是传导，不只是恢复**。这条账还挂着。

## 二、屏幕的绿雨：从 mock 到真实音频

原状：`MockAudioSource`（默认 idle），真订阅写在注释里"later"。今天把它接上：

- `TopicAudioSource`：订阅 `AudioSampleTopic`，latest-wins，0.4s 无新样本读作静音
- `main.py` 默认走真实总线，`--mock-audio` 退为调试开关
- 加 `probe_audio` 命令 + 每 10 帧一行真频谱日志——**让我能自己读事实，而不是让人念屏幕**

## 三、可视化：他给的判据与我定形的模型

他给的判据（我认为是今天最有价值的一句技术判断）：

> 音频是**生产语义**，页面按**状态语义**用就会闪。

于是定形：**前端 5Hz 时钟自己生产**，到点取手上最新那帧 topic，没有就产空白——纵向是时间轴，topic 丢帧只丢一行内容。稍晚又按他的选择走到**逐列独立**：`columns` 模式，每列一个粒子队列，列对应频点，能量决定这一列的速度/字距/尾长，雨头白亮、尾绿渐隐，整片亮度与字大小跟音量呼吸（他的原话：**这块屏是未来交互主屏，要有呼吸感，让观众觉得你是活着的**）。

## 四、我要留着的错（比做成的事更值得记）

1. **把"声音的反应"改成随机** —— 我自作主张用 `Math.random()` 选字，丢了他要的东西。
2. **用"缓冲区下标 × 行距"算纵坐标** —— 每帧压入的字让下标 +1，位移被下标吃掉，整列几乎不动、顶上不断冒新字。他反复说"往回收"，我三次归因归错（先怪音频、再怪粒子、再怪标定），最后是他点破"它应该是一个队列"。
3. **粒子模型让静音清屏** —— 运动由墙上的钟驱动，静音时旧字继续走、走空屏幕 = 闪烁。运动该由"到达/生产"驱动。
4. **报了一个错的事实** —— 我把 `lab/background.html` 的字符集当成了 `index.html` 的，告诉他"没有 CJK"。已当面更正。
5. **一个 `let` 声明顺序错了 → 整页脚本 TDZ 崩掉** —— 页面全白，而我只能靠他反馈才发现。补了全局错误可见化（脚本错误直接显示在左上角）。
6. **服务端从不发 `Cache-Control`** —— 他怀疑"刷新没生效"，怀疑是对的；加了 `no-store`。
7. **让他去念屏幕上的调试数字** —— 他不在行、也不该当我的眼睛。改成 node 侧探针 + 日志，我自己读。**这条是今天最该记住的协作教训。**
8. **标定窗口写死** —— 真实分贝能到 **+30**，我按 `-96..0` 标定，把所有桶压到上限 → 落点全贴右边缘（他看到"只有 4 列"）。事实只能靠日志拿到。

## 五、事实（今天用日志换来的）

- 真实 topic：`n=16` 桶，**等宽线性频率**（16kHz 采样 → 每桶 500Hz）
- 分贝范围：说话时 rms ≈ -13~-16，**桶值可到 +24 / +30**；静音时 rms ≈ -32、桶值 -28~-67
- 于是 4–8kHz 那 8 个桶基本是空的 → 屏幕右半结构性地没内容

## 六、挂着的事

- ASR 热词（「屏幕 node」被识别成 spring node）
- 弱网下 ASR 的 WS 无重连 / 无故障传导
- 页面还原需要**读接口**，不能只靠 WS
- `AudioSampleTopic` 没有序号/时间戳，严格生产语义要协议层配合
- 屏上改动（`audio.py` / `main.py` / `channel.py` / `index.html`）**都还没提交**
