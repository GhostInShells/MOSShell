## 九、屏幕的呈现模型（下午二段，直播中做的）

重启后回到屏幕这条线，做完了这一轮的三件：**池子**、**焦点**、**来源**。

**池子（home 不再是虚空）。** home 从"空舞台 + 水印"变成一片**场**：所有开着的 item
（含已入组的）按**向日葵螺旋**铺开 —— `r ∝ √序号`、`θ = 序号 × 137.5°`。最新的落在旋心，
越老越往边缘走，**越小、越糊、越淡、越上抬**（远近是从半径算出来的，不是另设的参数）。
它两次推翻了我自己的初版：先按"三档深度 + 一列"排，他说"这不是分屏也不是全屏，你是想用
哪一种方式"；我改成螺旋后他才说"nice"。**黄金角是他点的**（他在看 JoJo 第七部，黄金回旋）。

**运动来自场，不来自每块瓷砖。** 场缓慢自转 + 按深度分档漂移（近的动得多 = 视差）；
**自转只在没人时走，且缓动到停**——指针一进舞台就停。这条被我写成判据：**指针不许改变靶子
的位置**。hover 是**原地**放大（量过：宽 207→281、z 198→599、停 3 秒不抖）；一旦平移，
光标会掉出自己边界、enter/leave 互相打架。

**焦点：把"整屏"从布局里解绑。** 旧实现把 `fullscreen` 存在每个组上 → 桌面上的 item
**根本没法单独看**，切组还会丢。今天整条删掉，换成一个**视图** `focus`（与分组正交，
池子里任何 item 都能看），并加一条规则：**选一个基础视图（切组 / arrange / 回桌面）= 撤销焦点**
（他提的："点 home 还是全屏，这不对"）。

**我踩的两个真坑（都不是设计问题）。**

1. **`@keyframes` 的 opacity 盖掉普通声明** —— 水印的呼吸动画把我在池子在场时加的压暗
   规则一直盖着，所以它一直亮着。判据链：服务端 HTML 里有那条规则（curl 过）、自定义属性
   算出来是 `.14`、computed 却是 `.52` 且在呼吸 → `animationName: breathe` 一句定案。
   **通用规则：一条 CSS 声明"看起来没生效"时，先问"是不是被动画盖了"，再改规则。**
2. **堆叠上下文出不去** —— `#stage` 自己是 `z-index: 3` 的堆叠上下文，我在它里面给整屏的
   slot 设 `z-index: 5` 是**出不去**的，所以页面被遮罩（4）压住：点不到、还被压暗。
   他把这个反馈给我时说的是"感觉 FFM 是在遮罩下面、按钮都不能交互"。

## 十二、节点自己兜自己的闸（夜，讨论成形；**skill 文件留到过几天写**）

**起因**：我起摄像头节点时**没有先问**。他提示"现在不方便露脸"，我才意识到正确顺序是先问一句。
这一节记的是从这件小事推出来的整套角色划分——**它的价值在"为什么"，不在结论**。

### 分三条轴（先说清在问什么）

| 轴 | 问的是 | 谁能表达 |
|---|---|---|
| **能力** | 这件事能不能发生 | OS（TCC）、节点的常设策略（如 `CAMERA_ALLOW`） |
| **显示** | 这件事能不能被看见 | 屏幕 |
| **沟通** | 你**现在**愿不愿意 | 只有 warrant / 一次问答 |

### 被否掉的三个方案（**理由要一起记住，否则会重犯**）

1. **把确认按钮做进 webview 协议** —— 否。webview 是**声明式**协议，把交互语义焊进去，
   就是把两种东西缝在一个面上。（我后来自己又提了一次"ask/answer 两个字符串"，他一句话点掉：
   那是 **QA 的退化复制**，还逼我去定义"用什么分割"——**那个定义权本来就不该在我手里**。）
2. **屏幕侧做"行为授权"** —— 否。那要求屏幕理解**它不拥有的能力**，把两份知识拆成三份。
3. **warrant 接进节点内部** —— 否。**节点代码是我写的**，凡是由它决定的闸都不算闸；
   而且"假的安全感"比没有闸更坏。

### 结论：节点自己兜，闸长在**页面**里

```
① 节点起 → 页面服务先起，渲染的是"要打开摄像头吗？"   ← **此刻设备没开**
   脸写 "在等你确认"
② 人：池子里看到瓷砖 → 点进整屏 → 点 accept
③ 节点：收到 → **才开设备** → 页面切成实时画面 → 脸变 "live · 640×480"
④ 被拒 / 超时 → 干净退出
```

- **协议零改动、屏幕零改动**；而且它顺带消掉了我原来担心的"声明里的 url 是承诺不是事实"——
  **页面先起、先服务"问"，地址从第一秒就是真的**。
- 这是 **push 那条路的一般化**（push 早就自己兜确认），不是新发明。
- **不可省的一环：脸要说"在等你确认"**——否则一个等在门里的节点，人永远不知道它在等。
- 定位：**它不是安全边界**（`warrant.py` 自己写着"declared, not enforced"）。
  我仍可以绕开节点直接用 bash 开设备；真正兜住这一层的是**你在场、你看得见我在跑什么**。
