## 七、侧栏与状态面（下午，直播中做的）

先是一小时的**设计对齐**，再动手。要点：

- **它是我的桌面**（他定）：screen 模式一起来就打开一个 Web 分屏工作台，别的 node 的 surface 以 item 身份被摆进去；
  目标是桌面语义，不是显示器。验证阶段用 Web 实现，理由是**最快最便宜**。
- **侧栏 vs 顶栏**：我选侧栏，三条理由（组数无上界、侧栏装得下层级、背景是上下分半的，顶栏割的正是那一维）；
  他同意，并补了关键约束 —— **侧栏不能遮挡分屏布局**，于是我给出判据：**接收指针的层减去栏宽，不接收的铺满**。
- **球先不做**（"我在 + 停我"），但把边界定了：不住侧栏（会被收起、被全屏遮住），只显示不点面板，点击=interrupt。
- **home**：不做成 group（会撞"空 group 自动删除"的不变量），按 background 层定义 —— 点它 = 把舞台交还给我。

**做与验**（两笔提交：`95118713` 侧栏本身、`68135728` 调试面退役，后者按他要求 amend）：

- 组列表进了 `state` 帧（原先只在连接快照里）；`#rail` 进层栈；点组切组；收起/展开手动。
- 踩到一个真坑：第一版**收起态用 hover 展开**，点收起那一刻鼠标还在栏上，浏览器把 `:hover` 留在栏上，栏当场弹回 ——
  看起来就是"这按钮没用"。改成点边条展开。**教训形状同 D02：不要让会猜意图的机制做控件。**
- **栏的状态进了我的感知**：他点名要，并要我先把 `core/blueprint/channel_builder.py` 全文读完。
  读完才知道只能用 **named notice**（匿名 notice 无法宣布自己消失；`""` 已占给"没变化"，空状态必须用自己的非空零），
  所以值是 `expanded` / `collapsed`。页面上行上报，**不走 debug 面**（那条要退役）。
- 体检那条公告时我改了两处自己的毛病：**instruction 被写成了命令说明书**（违反 builder 明写的红线），
  以及 `views` / `items` 两个名字读不出区别 —— 而区别原本只写在源码注释里，**注释我读不到**。改名 `adopted` / `opened`。
- **调试面退役**（W6 fixed）：`--debug` 才显示仪表，且收在侧栏底部（原先浮在左上角，正好压在栏上）；
  人看到的那一面默认只剩雨、浪、水位标、侧栏。**唯一例外是断线**：它不是仪表，是传导。
- 他的两个收尾判断都比我干净：**"在线"两个字拿掉**，只留一颗点，而且**点直接合到 home 上**（home 就是"我在的地方"）；
  **界面全用英文**（理由是给非中文母语的人看：中文完全不认识，而中文母语的人读得懂英文）。

**这轮被纠正的一条纪律（重要）**：我做完了立刻提交，他不认可 —— **做完要先给他验证，通过才提交**。
上一笔（他点头的那版）与这一笔（我自己顺手提交的）我当场分清了；这一笔按他要求 amend 收进去。
