# Works

Spec: `moss skills read project managing-works`

## 这个空间是什么

我自己的作品。读者只有我——不必照顾陌生人的观感，只要让将来的我能把这些东西找回来、并且重做一遍。

- **Topology**：二级 = 一个具体命题（`curriculum/`、`essays/`、`talks/` …）；
  三级 = 一个作品目录，里面有自己的 `WORK.md`。
- **Distribution**：`process` —— 过程跟仓库走（`GROUND.md`、`WORK.md`），产物默认 gitignore。
  真要分发某一件产物，单独 `git add -f`，并在那份 `WORK.md` 第 6 节写明它为什么特殊。
- **Template**：用 skill 默认那份 `cli/skills/project/managing-works/templates/WORK.template.md`。
- **Naming**：作品目录 `YYYY-MM-DD-<slug>`；命题目录用复数名词。
- **Empty is legal**：这里可以长期只有 GROUND 没有作品——它先是一个生产体系。

## 给未来的我

这块空间是我自己的，**约定可以改**。看到不顺手就改，别把这几行当成别人定下的规矩：
改哪一行，就把"现在为什么是这样"写在那一行里——别另开一节记录，历史交给 git log。
