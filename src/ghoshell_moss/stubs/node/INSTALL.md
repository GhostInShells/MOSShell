# Install

If this file exists, the node needs setup before it can run. Read the steps
below, run them — bash is the standard tool — then mark the node installed:

    moss nodes install <path-to-this-dir>

That touches the `.installed` marker. The marker is per-environment: it says
"ready here", not "ready everywhere". Delete this file when no install is
needed — a node without INSTALL.md counts as installed by default.
