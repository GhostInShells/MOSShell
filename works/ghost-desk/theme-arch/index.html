切一个主题：三处各管一件事

颜色只在磁盘上的文件里。屏的进程里只有一个名字，浏览器里只有一套变量—— 三处各管一件事，谁也不替谁记颜色。
① 磁盘
你写的那份文件
一个人可以往这里放任意多份，屏不会数。
themes/kawaii-shell.json
themes/moss.json
…你放几个就是几个
vars — 颜色变量表
presence — 桌上站着谁：true / false / 一个页面路径
"presence": "works/ghost-desk/me-overlay/index.html"
按名字取
② 屏的进程
只记住一个名字
模型里没有一处颜色，只有"现在穿哪套"。
theme(name) — 命令进来，改这一个字段
ScreenModel.theme = "kawaii-shell"
广播 — 每个连着的窗口都收到；新连上的拿全量
/themes/<name>.json — 文件由这里递给页面
广播一帧
页面自己取
③ 浏览器
把名字变成画面
页面不缓存颜色，也不猜；它照着变量画。
:root — 变量逐个贴上去，CSS 里全是 var()
canvas — 字符雨与圆盘是位图，换主题要重画两张图集
化身 — 是谁、在不在：这两件由这份 JSON 决定；站哪里则看舞台上有没有内容，换主题时一起重算
matrix.mesh.screen:theme name="kawaii-shell" 加主题 = 放一个文件 切换 = 一条命令，不重启、不改代码
