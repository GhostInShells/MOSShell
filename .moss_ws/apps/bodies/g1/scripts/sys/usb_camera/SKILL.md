# G1 USB 与摄像头技能

## 调查命题

1. PC2 暴露了哪些 USB 接口？USB 2.0/3.0 各多少个？当前有哪些设备已连接？
2. 插入 USB 摄像头后，v4l2 能否识别？支持哪些分辨率和帧率？

## 架构决策

- USB 接口数量与类型 → 决定可同时外接多少设备（摄像头 + 可能的 USB 音频/MIC）
- v4l2 驱动能力 → 决定视觉方案：USB 摄像头直连 PC2 vs 网络摄像头 vs 外部方案
- G1 没有内置面向外部的摄像头，视觉需要外接方案

## 脚本

| 脚本 | 输入 | 输出 | 耗时 |
|------|------|------|------|
| `01_list_devices.sh` | 无 | lsusb 树形结构、所有 USB 设备详情 | <2s |
| `02_camera_check.sh` | 无 | v4l2 设备列表、每个设备支持的格式/分辨率/帧率 | <3s |
