# G1 网络技能

## 调查命题

1. PC2 有哪些网络接口？哪个接口连接 G1 内部交换机（192.168.123.x）？
2. PC1 (192.168.123.161) 和 LiDAR (192.168.123.120) 是否可达？
3. WiFi 射频是否开启？当前连接哪个 AP？信号强度如何？

## 架构决策

- 网络拓扑确认 → 决定 MOSS cell 的通讯 IP 绑定
- WiFi 状态 → 决定 PC2 能否自主联网、是否每次开机需手动开启
- 三节点连通 → 确认 DDS 通讯路径完整

## 脚本

| 脚本 | 输入 | 输出 | 耗时 |
|------|------|------|------|
| `01_interfaces.sh` | 无 | 所有网络接口配置、路由表、DNS | <1s |
| `02_reachability.sh` | 无 | PC1/LiDAR/外网的 ping 结果 | ~10s |
| `03_wifi_status.sh` | 无 | WiFi 开关状态、已连 SSID、信号强度 | <2s |
