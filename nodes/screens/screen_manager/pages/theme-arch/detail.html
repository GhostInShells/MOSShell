细节 what actually travels

一个主题文件里有五个键

name
文件名去掉后缀；也是 theme(name) 的参数
label
给人看的名字，一句话
description
这套场景是什么感觉
vars
颜色变量表（现在 62 个）；缺的键退回页面 :root 里那份默认
presence
桌上站着谁 —— 三件之一，见下

presence 的三种写法

true / 不写
用这块屏起屏时配的那个人（--presence 或 presence 命令）
false
空桌：人不出现，MOSS 四个字回正中
"一个路径"
这套场景自带的化身：换到它就换上，换走时原来那个人自动回来

总线上多出来的两帧

{"type":"theme", "name":"moss"} → 页面据此去取 /themes/moss.json
{"type":"state", "theme":"moss", "presence":"/local/…"} → 只有换人时才补这一帧

页面收到的三处落点

:root
62 个 CSS 变量逐个贴上去，var() 全自动跟着变
canvas
两张字色图集重画：雨尾 / 雨头 / 圆盘边 —— 位图不认变量
化身
是谁、在不在由主题定；站哪里看舞台上有没有内容
