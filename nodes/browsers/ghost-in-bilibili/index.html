ghost-in-bilibili

Chrome 扩展 → 本地 node。这个页面能打开 = node 在线。

① 安装扩展(一次)

  1. 地址栏打开 chrome://extensions
  2. 右上角打开「开发者模式」
  3. 点「加载已解压的扩展程序」,选这个目录:
…

旧路径装过的先在 chrome://extensions 移除,再重新加载。

② 交互

打开任意 B 站视频页,右上角有个球:灰 = 停,点一下 绿 = 运行(开始轮询)。

绿灯时旁边会出:输入框(回车发给 ghost)+ JS 审批区(模型下发的 JS,点 accept/deny)。

③ 下发 JS(测试审批回路)

page 填视频页完整 url(从事件日志里抄),body 填 JS。new Function(body)() 执行,用 return 返回值。
