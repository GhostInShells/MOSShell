# Live2D

MOSS 的 Live2D 虚拟形象躯体。一个 node（`avatar/`）驱动多套形象。

- **进入节点**：`avatar/NODE.md`（机制）、`avatar/avatars/README.md`（套件契约）
- **自建环境**：`avatar/INSTALL.md` 与 `avatar/skills/setup/`
- **AI 认知入口**：`CLAUDE.md`（方法论 / 范式真相）

快速验证（本地冒烟案例 miku）：

```bash
moss nodes run nodes/live2d/avatar -- --avatar miku
```

打开启动日志里的页面地址即可看见形象。
