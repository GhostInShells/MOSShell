# examples — 按视图拓扑摆好的样例

这里的目录结构**就是** [`../view-topology.md`](../view-topology.md) 的拓扑。
以后打磨某个视图，直接切到对应目录，不用再解释"我在说哪一层"。

```
examples/
  index.html                  图墙（先看这个）
  L0-swarm-map/               全部 swarm：星图 + 侧栏（列表是同一个模型的另一个投影）
  L1-swarm/
    planning/                 规划图：戴森壳 = features（含"按 feature / 按时间"两种铺法）
    resources/                资源图：零件架 + 装配图（组件是核心单位）
    tasks/                    任务图：领地内正在跑的 task
  L2-task/
    design/                   设计图：代码拓扑（蓝图语法，审计档）
    runtime/                  运行图：op / event 的流（带子语法）
  free/                       还没挂进拓扑的探索（02 三档、03 静息）
  shots/                      每个样例的定妆照（1280 宽 jpeg）
```

## 约定

- **一个目录一个视图**，`index.html` 即入口；一页只回答一个问题。
- 页面自包含、零依赖，`file://` 直接可开。
- 动效要么是呼吸（不携带信息），要么来自真实总量；不允许假事件。
- 改样式先改 `../brief.md` 里的规则，再改页面。
