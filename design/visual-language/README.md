# 命题：集群运行时的视觉语言

**问题**：一个 ghost 在 24/7 运行时，人类抬眼看到的应该是什么？——既要美，又要能审计。

## 现在的答案（D28）

三套语法，分工明确：

| 语法 | 回答 | 用在哪 | 怎么动 |
|---|---|---|---|
| **星辰** | 在哪、有多少、长成什么样 | 星图（L0）、戴森系统（L1） | 呼吸 + 缓慢公转 |
| **蓝图** | 凭什么、结构是什么 | 设计图（L2）、任何 item 详情 | 近乎静止 |
| **带子** | 在流什么、堵在哪 | 运行图（L2） | 匀速流动 |

拓扑：`L0 星图 → L1 戴森系统（多星 = workspace 树，每星一层壳 = features）→ L2 任务（设计 / 运行）`。
**缩放**换尺度，**换层**换问题 —— 两种语义不混。

## 已定的约束

- 隔离靠空白：没有共享事实的集群之间不画线。
- 有位置的动必须来自真实总量（核的呼吸频率 = running 数、货件数 = 在飞的 op、弧长 = 平均进度）。
- 只有 task 相关的东西"有意图地动"，其余是呼吸或静止。
- 主题不只是配色，是语法包。
