# design — 调研与设计阶段的物料

这里是**还没进代码的东西**：命题、原型、样例、被推翻的判断。
一进 `src/` 就不属于这里了。

## 规则

- **一个命题一个目录**。命题 = 一个可以被单独回答的问题，不是一个大主题。
- 每个命题目录一份 `README.md`：问题是什么、现在的答案是什么、还剩什么。
- 物料（原型 / 截图 / 样例）跟着命题走，**不散落在 feature 目录里**。
- `.ai_partners/features/` 只留**讨论提纲与索引**，指向这里 —— 那里是"这条工作流怎么推的"，
  这里是"推出来的东西长什么样"。
