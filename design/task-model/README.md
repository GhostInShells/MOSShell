# 命题：task 文档与组件模型

**问题**：如果 task 是第一公民、agent 不是，那么"一个 task"的**文件形态**是什么？

## 现在的答案（D28）

**task = BOM + 装配图。**

组成一个 task 的不是"一个 agent"，而是一组**组件**：

| 类型 | 例子 | 说明 |
|---|---|---|
| loop | task-loop | 驱动 op 序列 |
| agent-preset | `deepseek-flash / max` | 推理内核的预设 |
| skill | uv workspace / 前端可视化 | 可复用的动作知识 |
| tool | terminal / file_editor / co_browser | 真正碰世界的手 |
| boundary | `workspace` 路径 | 权限边界；子任务不跨它 |

**组装本身可以只是一份文档** —— 也就是下面这些样例的格式。

## samples

> 真实任务被选进来的理由只有一个：假任务会把图做得很好看，然后教错模型。
