# examples — 拓扑的例子，也就是记忆本体

这一层不是文档，是**语料**：每份 example 是一次真实发生过的 task，按 [`../../visual-language/view-topology.md`](../../visual-language/view-topology.md)
的拓扑写下来。以后做设计、写渲染、写反射，都从这里取样本 —— 因为只有真实发生过的东西，
才有资格当判据。

## 一份 example 长什么样

```
<id>-<slug>/task.md      任务文档（BOM + 图 + 边界 + 事实）
                          /notes.md  可选：当时踩的坑、被推翻的判断
```

`task.md` 的骨架见 `000-template/task.md`。它同时也是**未来 task document 的第一版草案**：
如果这套文件格式站得住，它就该是运行时真正读写的那份东西。

## 为什么要用真实任务

- 假任务会把图做得很好看，然后**教错模型**：真实任务的节点是不均匀的，有回头路，有废弃分支。
- 真实任务自带**事实链**（提交号、路径、退出码），审计档才有东西可点。
- 我们这一轮本身就在做一个 task（视觉探索），它天然是第三份样本。
