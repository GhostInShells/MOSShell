# 03 — 默认协作体系

**它先于 02**：不是先有集群再定分工，是先把分工定清楚，集群是它的载体。

## 他说

- 拓扑：**2 依赖 3**，协作体系先于运行时被定义。
- "整个 moshell 就运行在我手动调度的这个协作体系里" —— 今天的实际状态就是它的原型。
- 地基是 facts：执行者不靠上下文理解进度，靠 git commit / issues / features 理解进度；
  "这就是协作体系的核心基础"。

## 我的推断（未确认）

- 判断这一层做得好不好，标准是"一个没有上下文的执行者，只读这些事实就能判断出
  进度和下一步"。依据：地基那句 + 我每天开机就是这么理解进度的。
- 因此这一层的产物很可能不是"一个调度器"，而是**一组事实的形状约定**
  （谁写、写到哪、什么算一条、怎么关闭）。**不要当结论用。**
