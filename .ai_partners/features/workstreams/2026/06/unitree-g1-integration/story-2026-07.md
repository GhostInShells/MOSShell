## 0. 范式决策

**不进调试模式。** 运动模式是 MOSS 主场。进入调试模式的路径 (Damp → L2+R2) 不可靠: Sport 直接 L2+R2 会触发 PC1 状态机保护性故障, 且调试模式下 LocoClient RPC 全失效。遥控器在运动模式下全部按键/摇杆透传 wireless_remote[40], MOSS 在运动模式下协控, 遥控器保有急停权。

**机体模式是大状态机。** channel 不制造自己的状态体系 — 映射 G1 的 FSM 模式到授权范围。不同 FSM 模式自带不同的可用命令集。L1 + 组合键切换机体模式, F3 统一归零。

**两种交互模式。** 默认按键触发思考 (F1 = 输入信号), 可选切换到语音持续输入 (ASR → 触发思考)。不做连续聆听对话, 本期不做。

**两种感知。** 关键帧感知 (sensors 持续收集, 进 context_messages, pop() 进 memory) 和输入感知 (遥控器按键/ASR 触发 → signal → Ghost 响应)。

**砍掉 arm action, 只走 arms DDS。** Action 不可中断且无完成信号。DDS publish 停 = 真中断, publish loop 结束 = 完成确定的。

## 1. 整体 Channel 树

> **Note**: 具体 channel 划分和命名在实现阶段对齐。纯感知类可能会并为少数 sensor channel, 不拆这么细。

```
g1
  sensors                    # 关键帧感知 (始终可用, 具体拆分对齐设计)
    motion                   #   fsm_id, fsm_mode, tick
    imu                      #   rpy, quaternion
    joints                   #   当前关节快照
    remote                   #   遥控器按键 + 摇杆
    battery                  #   SOC
    listener                 #   ASR 结果流转 (angle/text/speaker/conf)
    trajectory               #   位置关键帧采样 (后期)
    vision                   #   视觉帧 (本期 P0/P1 — 熟模式, 难点在硬件对齐)
  body                       # 运动控制 (全部需授权)
    arms                     #   rt/arm_sdk DDS keyframe animation, 单 channel
                             #   详见 design/2026-06-30_g1_arms_animation.md
    move                     #   LocoClient RPC (需 locomotion 授权)
  led                        # 灯光控制 (默认授权)
  speaker                    # 音频输出. 主轨走 MOSS TTS. G1 内置 TTS 作为辅助轨道 (可能结合音频文件播放).
                             #   音频文件播放可能独立为 music channel. 具体对齐设计.
  system                     # 系统级 (默认授权)
    volume                   #   音量
```

`body` 下的全部命令 `available` 函数绑定授权状态。未授权时模型不可见。

## 2. 遥控器分配

| 键 | 层 | 语义 |
|----|----|------|
| L2 + B | 硬件 | 急停 Damp。不可绕过 |
| F1 | Ghost trigger | 输入信号, 唤醒思考。对应 state DAG 向上授权 |
| F3 | Ghost interrupt | 归零。取消所有授权, Ghost 回初始态 |
| Start | Channel interrupt | 中断当前 command loop (cancel + StopMove/停 publish) |
| L1 + 组合键 | 机体大状态机 | 模式切换。人不经过 Ghost 操作 |

按键回调路径: `_buttons.py` callback (reader 线程) → `loop.call_soon_threadsafe` 推 event → asyncio loop 内判语义层 → F1/F3 走 InterruptNucleus/InputSignalNucleus → Ghost; Start 走 channel 层 cancel event。

## 3. 授权体系

| 阶段 | 机体模式 | 默认授权 | 需 F1 授权 |
|------|---------|---------|------------|
| 坐姿开机 | Sit | sensors / led / speaker / system | 无 |
| 站起后 (乘客态) | Stand/Sport | 同上 + arms | move |
| 运动态 (全开) | Sport | 同上 + arms + move (限速) | — |

**站起是单向的。** Ghost 不能自己坐下。坐下需要人类按遥控器 L2+左。

**授权仪式**: 每次按 F1 向上授权, LED 颜色变化 + Ghost 确认。F3 归零, 灯光回到默认。

## 4. 用户故事

### 4.1 开机

G1 坐姿。开机, PC2 连接 WiFi, Mac SSH 登录。

```
moss-repl --mode unitree_g1
```

`channels.py` 模块级 `bootstrap()` → DDS 初始 + 三 client + monitor → 阻塞完成。

channel startup: LED 呼吸蓝 → TTS "我醒了, 当前状态 [battery/pose]" → 进入 idle。

idle 行为: LED 低亮度呼吸, arms 休止动画 (如果在站姿), 无其他输出。

### 4.2 对话唤醒: "你在吗"

人说话 → ASR (`rt/audio_msg`) → listener sensor 更新 → context_messages 中有最近 N 句对话记录。

人按 F1 触发 Ghost 思考。Ghost 读 sensors pop → 自我介绍 (姿势/电量/状态)。

如果 Ghost 介绍不够, 人追问。Ghost 读 `motion() / imu() / battery()` 报告细节。

### 4.3 LED 授权

人: "我怎么授权你控制灯光?" Ghost: "按遥控器 F1。之后我可以控制灯光。"

人按 F1 → Ghost 收到 signal → 确认授权。

Ghost 调 `led.set(r, g, b)` 演示。对话中配合语音切灯色。

灯控支持帧动画编排: `led.animate(frames=[...], interval=0.3)` 播放多帧序列。

### 4.4 站起来

人: "你能站起来吗?"

Ghost 先检查 `sensors.motion.pop().fsm_id` — 如果在 Sit(3), stand_up 命令可用 (因为机体模式决定了它)。

第一次调用 `body.stand_up()` → **不执行, 返回 Observe "请确认周围安全, 有人在背后辅助。再次调用以执行。"**

人确认后第二次调用 → 真执行 `LocoClient.StandUp()` → 等待 `fsm_id` 变化 → 确认站起成功 → 报状态。

站起后 Ghost 进入乘客态: arms 可用, move 需另授权。

**Note:** 站起前需要 script 20 实测确认 Sit→Stand 行为的准确时长和物理表现。吊架下不建议测试此场景。

### 4.5 手臂

人按 F1 授权手臂。arms channel 出现。Ghost:

- 休止 idling: arms 低幅度呼吸动画 (script 26 已确认 DDS 可行)
- 说话时: 小幅手势配合语音 (手掌转向听者, 抬手强调等)
- 需要实现: `arms.left.animate(keyframes: list[JointTarget], duration: float)` 和 `arms.right.animate(...)`

关键帧格式 (DDS motor_cmd):
```
{kJointIdx: target_angle_rad, ...}
```
50Hz 线性插值, kp/kd 需从 script 26 默认 60/1.5 调软到约 20/0.5。

**Idling 实现**: `channel.on_idle()` hook → 检查 `available` → 若允许, 启动 idling 动画循环 (子线程, publish loop)。新的 command 到达 → cancel 当前 idling → 执行命令动画 → 结束后恢复 idling。

### 4.6 转身找人

人站到 G1 背后: "能不能转过身来面对我?"

`sensors.listener.pop()` 获取最新 ASR 结果 (含 angle)。

`body.move.roll(angle: float)` 封装: 固定角速度 v_yaw × 预估时间。需要实机标定: v_yaw=N → T 秒 → 实际转了多少度 → 建查表。

非闭环。转完等下句 ASR → angle 趋近 90° 即面对。不够再转一次。

### 4.7 空间移动

人按 F1 授权 move。Ghost 确认: "收到移动授权, 我将限速行走。"

`body.move.walk(vx, vy, vyaw, duration)` — 封装 LocoClient Move + SetVelocity。

约束:
- 速度上限: vx < 0.30, vy < 0.15, vyaw < 0.30 (script 19 实测 0.25 稳定, 0.15 低于启动阈值)
- 空气墙: `sum(abs(vx * dt)) > max_distance` → 自动 StopMove → 报 Observe 终止
- Start 键: 任何时刻中断 move command loop → StopMove 立即发

空气墙不是安全机制 (安全 = 遥控器 L2+B), 是 Ghost 的自我约束。
