## Run Log (关键证据)

- **TC-001** (probe script, stdio): `open → connected, 13 tools`；`get-sum(2,3)=5`；`get-tiny-image` 返回图片 content。
- **TC-002** (probe script, streamable_http 3001): `open → connected, 13 tools`；`get-sum(5,7)=12`。
- **TC-003** (shell facade): `mcp.everything_http` notice = `get-sum(`a` (number, required): First number, `b` (number, required): Second number) — Returns the sum of two numbers`；interface 仅 `call`/`acall`。
- **TC-004** (shell): `<mcp.everything_http:call tool="get-sum">{"a":5,"b":7}</...>` → `The sum of 5 and 7 is 12.`。
- **TC-005** (shell): `<mcp.everything_http:acall tool="get-sum">{"a":10,"b":20}</...>` → `The sum of 10 and 20 is 30.`；facade 显示 `@nonblocking @observe`。
- **TC-006** (shell): `mcp:add` → `[mcp:everything_http] config added (not open)`；`mcp:list` 显示 `Configured (not open)`。
- **TC-007** (shell): `mcp:close` → `closed` + 子 channel `removed`；`mcp:list` 仍显示 `everything_http`（not open）。
- **TC-008** (shell): `mcp:remove` → `removed from config`；`mcp:list` 空。
- **TC-009** (CLI): `moss mcp add --json '{"name":"bad-name",...}'` → `[mcp] invalid server name 'bad-name' (must match [a-zA-Z_][a-zA-Z0-9_]*)`。
- **TC-010** (probe script): `call("add")`（不存在的 tool）→ `[mcp:everything/add] error: MCP error -32602: Tool add not found`，兜成 Observe 不抛异常。
- **TC-011** (CLI): `moss mcp add` → `list`（demo 显示）→ `remove` → `list`（空），往返一致。
- **TC-012** (shell, 8 步): list(空) → add → open → 子 channel 长出 → call → close → list(保留) → remove，全绿。
